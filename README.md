## 🧑‍💻 À propos

Développeur Web Full-Stack orienté **JavaScript** et **PHP**, j'aime construire des choses utiles, propres et bien pensées.

Je m'intéresse autant au front qu'au back, avec une vraie attention portée à l'expérience utilisateur, à la performance et à la qualité du code. Curieux par nature, je m'investis aussi dans l'**IA** et l'**automatisation** pour améliorer mes workflows.

> 🎯 Actuellement à la recherche d'une **alternance** pour continuer à progresser au sein d'une équipe et contribuer à des projets concrets.

## 📐 Méthodologie & valeurs

Je crois qu'un bon développeur, c'est avant tout quelqu'un qui écrit du code que les autres peuvent comprendre.

- ✅ **Code propre** — nommage clair, architecture pensée pour durer
- 📝 **Documentation** — un README soigné, des commentaires utiles
- 🧪 **Bonnes pratiques** — tests, validation, revue de code
- 🤝 **Collaboration** — Git Flow, pull requests, communication
- 📈 **Apprentissage continu** — veille tech, side projects, curiosité
